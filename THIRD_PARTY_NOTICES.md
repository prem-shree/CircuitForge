# Third-party notices and symbol licensing

CircuitForge bundles schematic symbols from one external library. Every symbol's
`metadata.json` has an `origin` block that records where it came from, its
license and any modifications.

## Bundled

### chris-pikul/electronic-symbols: MIT

- Source: https://github.com/chris-pikul/electronic-symbols
- License: MIT, Copyright (c) 2022 Chris Pikul. The full text is in
  [`src/symbols/LICENSE-electronic-symbols.txt`](src/symbols/LICENSE-electronic-symbols.txt).
- Used for 44 symbols: resistor, variable resistor, potentiometer, capacitors, inductor,
  transformer, crystal, fuse, switches, all diodes, BJTs, MOSFETs, JFETs, op-amp,
  comparator, sources, battery, logic gates, buffer/tri-state buffer, flip-flops,
  ADC, DAC and ground.
- Modifications, made by [`scripts/import-symbols.mjs`](scripts/import-symbols.mjs):
  - Scaled by 0.4 so the 25px source grid lands on CircuitForge's 10px routing grid.
  - Stroke width normalized and colors switched to `currentColor`.
  - Pin anchors and body boxes added as metadata.
  - Voltage/current sources and the battery redrawn vertically (positive on top) from
    the upstream geometry, so the polarity marks and the sine stay upright.
  - Tri-state buffer derived from the buffer by adding an enable lead.
- Obligation: keep the MIT copyright notice and license text with any redistribution.
  The license file ships in `src/symbols/`. Keep it if you vendor the symbols elsewhere.

### Original CircuitForge symbols

VCC/VDD/VSS rails, input/output terminals, test point, net labels, junctions, and every
rectangular IC symbol (555, generic IC, microcontroller, memory, regulator, mux/demux,
encoder/decoder, counter, register, connector) are original. The rectangular ones are
generated by `src/symbol-loader/index.js`. They fall under the CircuitForge project's own license.

## Evaluated, not bundled

| Library | License | Why not bundled |
|---|---|---|
| [basverdoes/ElectricalSymbolLibrary](https://github.com/basverdoes/ElectricalSymbolLibrary) | Symbols in `src/symbols/` are CC0 1.0; other files are CC BY-NC-SA 4.0 | IEC/European drawing style, no pin metadata. Only the CC0 symbol files may be imported. Never import the NC-licensed files. |
| [KiCad symbol libraries](https://www.kicad.org/libraries/license/) | CC-BY-SA 4.0 with a design-use exception | The exception covers *designs*, not redistributing library collections. A converted KiCad symbol set shipped with this app would have to be CC-BY-SA. Also `.kicad_sym`, not SVG. |
| [sjgallagher2/SchematicSymbolsSVG](https://github.com/sjgallagher2/SchematicSymbolsSVG) | MIT | Inkscape drawings without pin metadata and on an inconsistent grid. Usable later with an importer mapping. |
| [tscircuit/schematic-symbols](https://github.com/tscircuit/schematic-symbols) | MIT | Has port metadata (TypeScript `defineSymbol`). A good candidate for a second importer. |
| `circuit-symbol-svg`, `circuitinsight-symbols` | n/a | No repository with these names could be found. |

## Build tooling

- esbuild (MIT) is a development dependency only; it is not shipped in `dist/`.
- The UI loads Inter and JetBrains Mono from Google Fonts (SIL OFL 1.1) and falls back to
  system fonts offline. Exported schematics use Helvetica/Arial and embed no fonts.
