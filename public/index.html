    API

    The rendering engine is pure JavaScript with no DOM dependency, so the same code runs in this page, in Node, and behind an HTTP API. This static site has no backend. The server/ folder in the repository contains a reference HTTP server.

    Endpoints planned

    POST /api/v1/render     { "circuit": { … }, "format": "svg" | "json" }
POST /api/v1/validate   { "circuit": { … } }
Header: Authorization: Bearer <API_KEY>

    format: "png" and "pdf" are reserved and currently return 501 from the reference server. In the browser those formats are produced by the Export menu.

    In this page

    The engine is exposed as window.CircuitForge for scripting from the console:

    const { svg, errors } = CircuitForge.render(circuit);
CircuitForge.validate(circuit);   // { valid, errors, warnings }
CircuitForge.types();             // supported component types
